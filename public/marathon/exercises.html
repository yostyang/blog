力量训练Strength

跑步专项、单腿稳定与后链为主，中等负荷、控制优先。每周 2 次，跑后或单独进行。

高脚杯深蹲Goblet Squat

3×10周一 / 周四 · 力量

壶铃抱在胸前，髋向后坐，膝盖跟着脚尖走。

3×10
周一 / 周四 · 力量

怎么做

  1. 双脚与肩同宽，脚尖略外展 15°
  2. 壶铃抱在胸口，肘部朝下
  3. 髋向后坐同时屈膝下蹲，胸口保持抬起
  4. 蹲到大腿接近平行，脚掌三点均匀受力
  5. 脚掌推地起身，顶端夹臀但不超伸

要点

  • 全程膝盖对着第二脚趾
  • 下蹲时重心落在中足，不是前掌
  • 蹲不下去先垫高脚跟 2 cm 练

常见错误

  • 膝盖内扣——主动外展，想着「把地面撕开」
  • 脚跟离地——重心前移了，先减小下蹲深度
  • 腰塌、胸口掉——核心收紧，别用腰起身

罗马尼亚硬拉Romanian Deadlift

3×10周一 / 周四 · 力量

膝盖微屈并固定，靠髋向后推把杠铃放下去。

3×10
周一 / 周四 · 力量

怎么做

  1. 站距与髋同宽，杠铃贴住大腿
  2. 膝盖微屈，之后全程锁定这个角度
  3. 髋向后推，杠铃贴着腿往下滑
  4. 滑到膝下、感到腘绳肌拉紧就停
  5. 臀部发力把髋推回来，站直不后仰

要点

  • 杠铃离身体越近越省腰
  • 只做到背能保持中立位的幅度
  • 起身靠臀，不靠腰

常见错误

  • 做成了深蹲——膝盖角度全程不能变
  • 弓背——幅度超过当前柔韧性，减量
  • 杠铃向前飘——贴身走，像刮腿

保加利亚分腿蹲Bulgarian Split Squat

3×8/腿力量 · 弱侧优先

后脚搭在凳上，前脚承重，直上直下。

3×8/腿
力量 · 弱侧优先

怎么做

  1. 后脚脚背搭在凳上，前脚向前迈一步
  2. 躯干略前倾约 10°
  3. 下蹲到前腿大腿接近平行
  4. 前脚掌发力起身，膝盖跟着脚尖走

要点

  • 前脚离凳越近，膝盖压力越大
  • 先徒手做稳，再负重
  • 弱侧先做，多做 1 组

常见错误

  • 后腿蹬地代偿——把注意力放在前脚
  • 左右晃动——放慢速度，减少负重
  • 前膝内扣——外展髋，膝盖对脚尖

单腿臀桥Single-Leg Glute Bridge

3×12/腿力量 · 弱侧 +1 组

脚跟发力顶髋，到肩-髋-膝一条线就停。

3×12/腿
力量 · 弱侧 +1 组

怎么做

  1. 仰卧屈膝，一脚踩地，另一腿伸直抬起
  2. 先收腹，让腰贴地
  3. 脚跟推地顶髋，直到肩、髋、膝成一条线
  4. 顶端停 1 秒夹臀，再缓慢落下

要点

  • 顶到一条线就够，再高就是腰椎代偿
  • 抬起那条腿保持与身体同线
  • 离心慢放比顶起更重要

常见错误

  • 用腰顶——先收腹再发力
  • 骨盆歪斜——抬腿一侧不要掉
  • 脚离臀太远——腘绳肌会抢臀肌的活

提踵Calf Raise

3×15周一 / 周四 · 力量

前脚掌踩台阶边缘，慢下快上，全程拉满幅度。

3×15
周一 / 周四 · 力量

怎么做

  1. 前脚掌踩在台阶边缘，脚跟悬空
  2. 先降到脚跟低于台阶，感到小腿被拉长
  3. 前脚掌发力顶到最高点，停 1 秒
  4. 用 3 秒慢慢放下来

要点

  • 直腿练腓肠肌，屈膝练比目鱼肌，两种都做
  • 跑量大的时候减组数不减幅度
  • 踝关节是跑步最容易出问题的地方

常见错误

  • 弹震借力——离心放慢就没法弹
  • 幅度太小——上下都要拉满
  • 膝盖锁死——留一点点屈

平板支撑Plank

40″力量 / 核心

肘在肩下，夹臀收腹，身体一条线。

40″
力量 / 核心

怎么做

  1. 前臂撑地，肘关节在肩正下方
  2. 脚尖蹬地，把身体撑成一条直线
  3. 收腹夹臀，肋骨向下收
  4. 保持匀速呼吸，别憋气

要点

  • 时间不是目标，姿势才是
  • 撑不住就停，别硬撑到塌腰
  • 能撑 60 秒就加难度，不用加时间

常见错误

  • 塌腰翘臀——夹臀收腹
  • 耸肩——肩胛骨向下沉
  • 憋气——呼吸乱了就结束这一组

死虫Dead Bug

3×10/侧力量 · 抗旋核心

腰始终贴地，对侧手脚慢慢伸出去。

3×10/侧
力量 · 抗旋核心

怎么做

  1. 仰卧，双手指向天花板，髋膝各 90°
  2. 腰背压住地面，全程不离地
  3. 对侧手脚同时缓慢伸展
  4. 回到起点，换另一侧

要点

  • 腰一离地就是幅度太大，收回来一点
  • 越慢越难，也越有用
  • 呼气时伸展，吸气时收回

常见错误

  • 腰拱起——减小幅度，只做能贴地的范围
  • 动作太快——慢才是重点
  • 憋气——伸展时呼气

鸟狗Bird Dog

3×10/侧力量 · 抗旋核心

四点支撑，对侧手脚伸直，骨盆不晃。

3×10/侧
力量 · 抗旋核心

怎么做

  1. 手在肩下、膝在髋下，四点支撑
  2. 收腹，先把骨盆调平
  3. 对侧手脚同时伸直到与地面平行
  4. 停 2 秒，慢慢收回

要点

  • 想象腰上放了一杯水，不能洒
  • 手脚伸直但不要抬过髋
  • 比死虫更考验骨盆控制

常见错误

  • 骨盆旋转——放慢，幅度减小
  • 抬头看前方——颈椎保持中立
  • 腿抬太高——超过髋就会塌腰

平衡与稳定Balance

提升本体感觉与踝、髋稳定，降低崴脚与代偿风险。每周 2–3 次，10–15 分钟。

单腿站立Single-Leg Stand

3×30″/腿平衡 2–3 次/周

从睁眼到闭眼，从硬地到软垫，逐步加难度。

3×30″/腿
平衡 2–3 次/周

怎么做

  1. 单脚站立，另一腿抬起，膝盖抬到髋高
  2. 目视前方一个固定点，保持 30 秒
  3. 稳定后闭眼，再进阶到软垫
  4. 两侧对比，弱侧多做一组

要点

  • 这是所有平衡训练的起点
  • 闭眼版本才真正练本体感觉
  • 两侧差距超过 10 秒就要重点补弱侧

常见错误

  • 靠身体大幅晃动硬撑——先扶墙，逐步撤手
  • 一直看脚——目光固定远处一点
  • 只练强侧——弱侧优先

单腿硬拉触地Single-Leg RDL

3×8/腿平衡 · 纠偏训练

支撑腿微屈，髋向后推，手向地面探。

3×8/腿
平衡 · 纠偏训练

怎么做

  1. 单脚站立，支撑腿微屈
  2. 髋向后推，另一腿向后伸直
  3. 手向地面探，背部保持中立
  4. 感到支撑腿腘绳肌拉紧就起身

要点

  • 后腿伸直是平衡的关键，不是装饰
  • 先徒手，能稳住再拿壶铃
  • 直接对着左右平衡的短板练

常见错误

  • 骨盆打开——后腿脚尖朝下、两侧髋保持水平
  • 弓背——只做到背能保持平的幅度
  • 支撑腿膝盖内扣

单腿提踵平衡Single-Leg Calf Balance

3×12/腿平衡 2–3 次/周

单脚提踵，顶端停住不掉下来。

3×12/腿
平衡 2–3 次/周

怎么做

  1. 单脚站立，另一腿抬起
  2. 前脚掌发力顶到最高点
  3. 顶端停 2 秒，保持平衡
  4. 用 3 秒慢慢放到底

要点

  • 踝关节稳定性的核心动作
  • 顶端停顿比次数重要
  • 跑量高峰期减量不减频率

常见错误

  • 落地砸下来——离心放慢到 3 秒
  • 脚踝外翻——想着大脚趾压地
  • 膝盖锁死

站姿髋绕环Standing Hip Circle

每侧 8 次跑前动态热身

单腿站立，另一腿画圈，髋关节走满幅度。

每侧 8 次
跑前动态热身

怎么做

  1. 单脚站立，可扶墙保持平衡
  2. 抬起一条腿，膝盖抬到髋高
  3. 向前 → 外 → 后缓慢画一个大圈
  4. 每侧 8 次，再反方向 8 次

要点

  • 跑前动态热身用，别做成静态拉伸
  • 圈越大越有效，但骨盆要稳住
  • 配合 90/90 髋旋转效果更好

常见错误

  • 用腰代偿——骨盆保持水平
  • 圈画得太小——等于没做
  • 速度太快——慢才能到关节末端

蚌式Clamshell

3×12/侧平衡 · 臀中肌

侧卧屈膝，脚跟并住，上面膝盖打开。

3×12/侧
平衡 · 臀中肌

怎么做

  1. 侧卧，髋膝各屈 90°，脚跟并拢
  2. 骨盆保持垂直于地面
  3. 上面膝盖向上打开，脚跟不分开
  4. 顶端停 1 秒，慢慢落下

要点

  • 练的是臀中肌——跑步时防膝内扣的关键
  • 背靠墙做更容易找到感觉
  • 弱侧多做 1 组

常见错误

  • 骨盆向后倒——背靠墙就不会
  • 幅度过大用腰代偿——减小到能控制
  • 速度太快——慢起慢落

髋部放松Hip Release

先把紧的地方松开，再把弱的地方激活——只拉伸不练臀，几天后还会紧回来。每晚 12–15 分钟。

半跪髋屈肌拉伸Half-Kneeling Hip Flexor

2×45″/侧每晚放松 12–15 分钟

先夹臀把骨盆后卷，再往前推——顺序错了就白拉。

2×45″/侧
每晚放松 12–15 分钟

怎么做

  1. 半跪姿，后膝垫软垫
  2. 先夹臀、骨盆后卷（这一步是关键）
  3. 保持骨盆后卷，重心缓慢前移
  4. 感到后腿髋前侧拉紧，停 45 秒

要点

  • 骨盆不后卷，拉到的全是腰
  • 对侧手可以向上举，加大幅度
  • 每晚做，休息日也做

常见错误

  • 直接往前顶——腰会酸，髋没拉到
  • 骨盆跟着前倾——夹臀
  • 憋气——呼吸要长

沙发拉伸Couch Stretch

2×30–45″/侧每晚放松 12–15 分钟

后脚背搭高，膝盖贴地，躯干慢慢立起来。

2×30–45″/侧
每晚放松 12–15 分钟

怎么做

  1. 后脚背搭在沙发或凳面上
  2. 后膝贴地，垫软垫
  3. 先卷骨盆夹臀，把腰放平
  4. 躯干缓慢立起，感到股四头与髋前侧拉长

要点

  • 比半跪拉伸更针对股直肌
  • 立不起来就先把后脚放低
  • 一开始别追求幅度

常见错误

  • 塌腰代替伸展——先卷骨盆
  • 后膝直接压硬地——垫软垫
  • 一上来幅度太大——循序渐进

4 字 / 鸽子式Figure-4 / Pigeon

2×45″/侧每晚放松 12–15 分钟

前腿折叠、后腿伸直，髋摆正再往下沉。

2×45″/侧
每晚放松 12–15 分钟

怎么做

  1. 前腿屈膝横放，小腿尽量与身体垂直
  2. 后腿向后伸直
  3. 髋摆正，不要倒向一侧
  4. 躯干缓慢前倾到能承受的深度

要点

  • 拉的是臀部深层，不是膝盖
  • 臀部垫高一点会舒服很多
  • 膝盖有不适就换成 4 字坐姿

常见错误

  • 髋歪向一侧——垫高臀部再试
  • 膝盖疼——减小屈膝角度或换动作
  • 硬往下压——呼吸放松，让重力工作

世界最伟大拉伸World's Greatest Stretch

3/侧 · 40″跑前动态热身

弓步 → 手撑地 → 转体抬手，一个动作打开三个方向。

3/侧 · 40″
跑前动态热身

怎么做

  1. 大步弓步，前脚掌踩稳
  2. 同侧手撑地，另一手向上打开转体
  3. 转体保持 5 秒，感受胸椎打开
  4. 回正，重心前移拉后腿髋前侧

要点

  • 跑前动态热身首选
  • 转的是胸椎，不是只抬手
  • 后腿伸直、脚跟压地

常见错误

  • 后腿塌——后膝伸直，脚跟压地
  • 只转手不转胸——眼睛跟着手走
  • 憋气——转体时呼气

泡沫轴放松Foam Roll

各 30–45″每晚放松 12–15 分钟

慢滚，遇到紧点停住深呼吸，别在骨头上滚。

各 30–45″
每晚放松 12–15 分钟

怎么做

  1. 把泡沫轴放在目标肌群下方
  2. 用体重压住，缓慢来回滚
  3. 遇到紧点停住 20–30 秒，深呼吸
  4. 每个部位 30–45 秒

要点

  • 慢才有效，快等于按摩皮肤
  • 股四头、大腿外侧上方、臀，三个部位就够
  • 滚完再激活，效果才留得住

常见错误

  • 在髂胫束上硬滚猛压——很痛且帮助有限
  • 滚得太快——没有时间让组织放松
  • 滚腰椎——避开，只滚肌肉

跑步技术Running

躯干、落脚点、步频。技术不是跑快了才练，是每次跑步都在练。

跑步姿态Running Form

全程每一次跑步

身体微前倾、落脚在重心下方、步频优先于步幅。

全程
每一次跑步

怎么做

  1. 躯干直立略前倾 5–10°，不要弯腰
  2. 手臂前后摆，肘约 90°
  3. 落脚点在重心正下方，不要跨大步
  4. 步频优先，步幅是结果不是目标

要点

  • 步频提到 175–180 会自然减小跨步
  • 累的时候最先垮的是姿态
  • 先在轻松跑里练，别在质量课里改动作

常见错误

  • 跨大步刹车——提高步频，落地放轻
  • 弯腰塌肩——想象胸口领跑
  • 手臂横摆过身体中线——前后摆

加速跑Strides

4×20″轻松跑之后

20 秒从 7 成加到 9 成，不冲刺，走回来恢复。

4×20″
轻松跑之后

怎么做

  1. 轻松跑之后进行
  2. 20 秒内从 70% 逐渐加到 90%
  3. 保持放松，步频高、落地轻
  4. 走回起点，完全恢复再做下一次

要点

  • 目的是唤醒神经，不是练体能
  • 留 10% 余地，绝不全力
  • 赛前一周的唤醒跑就靠它

常见错误

  • 变成冲刺——姿态会垮
  • 耸肩、手臂僵——放松肩膀
  • 在已经很疲劳时做

弓步走 + 转体Lunge with Twist

6 步跑前动态热身

弓步下沉，同侧手撑地转体，跑前动态热身用。

6 步
跑前动态热身

怎么做

  1. 向前跨一大步成弓步
  2. 前腿同侧的手向地面探
  3. 另一手向上打开，胸椎跟着转
  4. 起身换边，共 6 步

要点

  • 把髋前侧和胸椎一次打开
  • 步幅大一点才有拉伸感
  • 跑前做，不做静态拉伸

常见错误

  • 前膝内扣——膝盖对脚尖
  • 只转手臂——胸椎跟着转
  • 步幅太小——等于原地踏步
